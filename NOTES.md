# ClipArtCraft notes

- Started 2026-10-31 as the shared library for the Craft apps (the apps keep their own copies of code; the library data is what is shared).
- Works both ways: offline from disk (Chrome/Edge share browser storage between file:// pages) and hosted together on one site.
- Library format is the one ImageCraft's Split a sheet exports (library.json + PNG/SVG).
- ImageCraft's Split a sheet adds straight into the library (Add to the clip-art library, with a category).
- Montage Slicer (js/slicer.js, window.ClipArtSlicer): a copy of ImageCraft's splitSheet/sheetItem (Lab paper model from a 3% border ring, grow by gap/2, connected parts, reading order, exterior-only background removal, defringe) plus a Grid mode (rows × columns, inset per cell; each cell's picture found with one join-everything split and cut out). Click a box to leave it out. Settings except names and category are kept in localStorage.
- Slicer always makes an SVG. SVG sheets: drawn at 2,000–4,000 px to find boxes; svgCut keeps shapes whose root-space bbox (getBBox × getScreenCTM relative to the root) meets the box, drops shapes covering half the sheet (the background), and sets the viewBox to the box. Each cut remembers its box on the sheet (img.at).
- Grid: contentBox() leaves plain margins off (corner colour, tolerance 40). Test sheets: glossy remakes cut cleanly by Find; flat icons on white tiles lose white parts (tile white = paper white); coloured cells with long shadows need Grid (36/36, shadows gone).
- Next: an "Insert clip art…" picker for the other apps (each its own copy), tags and categories from Print Shop-style groups, maybe guess the grid size by itself.
- 2026-10-31 clip-art server (server/): clipart-server.js (Node 22.5+, node:sqlite built in; MySQL/MariaDB through the optional mysql2 package) and clipart-server.php (PDO: SQLite or MySQL/MariaDB), the same API (server/API.md). A library = database + files folder; JSON + files is the export/import/moving format; `copy FROM TO` moves between them. Names unique per library (_002…). CORS open; writes from localhost or with the x-craft-key header. Columns added later (type, style, form) are added to old databases on open. Tested: Node+SQLite, PHP 8.2+SQLite and PHP+MariaDB 10.11 (throwaway Docker containers) give identical answers. Node+MySQL (mysql2) not tested yet.
- Item types: clipart and model (3D mesh in the `model` file; png/thumb are pictures of it). Rendering a model at an angle in the app is still to do.
- Import pictures (js/importer.js, js/formats.js = own copy of ImageCraft's readers + pages(): TIFF pages, ICO sizes, animation frames via ImageDecoder). Kind (colour/grey/bw) from chroma and two-tone share; bw → ink (alpha from darkness; white ink on dark paper). Copies by 64-bit difference hash (Hamming ≤ 4). Seamless = opposite edges as alike as neighbouring columns, and edges not plain. JPEG 2000 / JPEG XL need decoders (not added; the browser is tried first).
- Naming (js/namer.js): CLIP ViT-B/32 q8 on wasm; ~700 words in 22 categories, plus styles, forms and eras as prompts; word directions worked out once and cached (Cache API 'clipartcraft-ai'). Plain cosine works better than centring for picture-to-word. Smart naming = file words when real (camera/scanner names and words like page/scan are ignored), else the AI's.
- Working area (js/work.js, IndexedDB 'craft-clipart-work'): sources kept with a "made" count; the slicer and importer add to it; items carry `sheet` (the source id).
- Next: render 3D models at an angle; montage sheet maker (pages of chosen clip art, packs); "Insert clip art…" picker for the other apps; JP2/JXL decoders (ask first); PDF pages; sheets on the server.
- Setup page (server/setup.html, served at /setup by both servers): admin login (PBKDF2-SHA256, 100k rounds, hex; Node pbkdf2Sync and PHP hash_pbkdf2 give the same), connections list (sqlite/mysql/json; PHP has no json), Test (opens it, makes the MySQL database if missing: 1049 → CREATE DATABASE utf8mb4), Save (a connection without password keeps its saved one, matched by id), Copy (both names must exist). Settings in clipart-settings.php ("<?php exit; ?>" first line + JSON), shared by Node and PHP; old clipart-server.json / clipart-config.php are moved over once. Tested on PHP 8.2 + MariaDB 10.11 (Docker) with real clicks, and Node (setup from another address). Node + MySQL needs mysql2 (not installed).
